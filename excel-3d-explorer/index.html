THE PARADIGM SHIFT

Dynamic Arrays Changed Everything

Before dynamic arrays, every formula returned a single value. Now, a single formula can spill results across multiple cells automatically. This is the biggest change to Excel's calculation engine in 30 years.

🚫

The Old Way

=INDEX($B$2:$B$100, SMALL(IF($A$2:$A$100="Sales", ROW($A$2:$A$100)-ROW($A$2)+1), ROW(1:1)))
  • Ctrl+Shift+Enter required (CSE arrays)
  • Must guess output size in advance
  • Nested INDEX/MATCH/IF combos
  • Helper columns everywhere
  • Fragile and hard to audit
⚡

The New Way

=FILTER(B2:B100, A2:A100="Sales")
  • Results spill automatically
  • Dynamic output size
  • Clean, readable formulas
  • No helper columns needed
  • Composable — chain functions together
DYNAMIC ARRAY

FILTER

=FILTER(array, include, [if_empty])

Extract rows that meet your criteria — like a WHERE clause right in your spreadsheet. No more CSE array formulas or helper columns.

🔴 Before (INDEX/MATCH/IF)

=IFERROR(INDEX($B$2:$B$1000, SMALL(IF($C$2:$C$1000>100000, ROW($C$2:$C$1000)-1), ROW(A1))),"") CSE array + drag down for each row

🟢 After (FILTER)

=FILTER(A2:D1000, C2:C1000>100000, "No results") Single formula, auto-spills all matching rows
🚀 ETL Parallel: SQL WHERE, Spark .filter(), dbt WHERE clause, Databricks filter transformation
DYNAMIC ARRAY

SORT / SORTBY

=SORT(array, [sort_index], [sort_order])

Dynamically sort any range by one or more columns. Like ORDER BY for your spreadsheet. SORTBY lets you sort by a column that isn't even in your output.

🔴 Before (SMALL/LARGE + INDEX)

=INDEX($A$2:$D$100, MATCH(SMALL($C$2:$C$100, ROW(1:1)), $C$2:$C$100, 0), 1) Helper column + SMALL ranking + INDEX retrieval

🟢 After (SORT)

=SORT(A2:D100, 3, 1) Sort by column 3, ascending. Done.
🚀 ETL Parallel: SQL ORDER BY, Spark .orderBy(), Pandas .sort_values(), Databricks sort transformation
DYNAMIC ARRAY

UNIQUE

=UNIQUE(array, [by_col], [exactly_once])

Extract distinct values instantly — your spreadsheet's DISTINCT operator. Combine with SORT and FILTER for powerful data deduplication.

🔴 Before (COUNTIF helper)

=IF(COUNTIF($A$1:A1, A2)=0, A2, "") Helper column + drag down + manual cleanup of blanks

🟢 After (UNIQUE)

=UNIQUE(A2:A1000) One formula returns all unique values
🚀 ETL Parallel: SQL SELECT DISTINCT, Spark .distinct(), Pandas .drop_duplicates(), dedup transformation
MODERN LOOKUP

XLOOKUP

=XLOOKUP(lookup, lookup_array, return_array, [not_found], [match_mode], [search_mode])

The definitive replacement for VLOOKUP, HLOOKUP, and INDEX/MATCH. Looks in any direction, returns multiple columns, supports wildcards, and has a built-in error handler.

🔴 Before (VLOOKUP / INDEX-MATCH)

=IFERROR(INDEX($D$2:$D$500, MATCH(G2, $A$2:$A$500, 0)), "Not Found") Lookup column must be leftmost for VLOOKUP, or use INDEX/MATCH

🟢 After (XLOOKUP)

=XLOOKUP(G2, A2:A500, D2:D500, "Not Found") Any direction, built-in default, binary search option
🚀 ETL Parallel: SQL JOIN / LEFT JOIN, Spark .join(), Pandas .merge(), Databricks lookup transformation
FORMULA ENGINEERING

LET & LAMBDA

=LET(name1, value1, ..., calculation)

=LAMBDA([param1], ..., calculation)

LET introduces named variables inside formulas — compute once, reuse many times. LAMBDA lets you create reusable custom functions without VBA. Together, they bring software engineering principles to spreadsheet formulas.

🔴 Before (Repeated calculations)

=IF(SUMPRODUCT((A2:A100="Sales")*(C2:C100)) / COUNTIF(A2:A100,"Sales") > SUMPRODUCT((A2:A100="Sales")*(C2:C100)) / COUNTIF(A2:A100,"Sales") * 0.9, "Above", "Below") Same sub-expression calculated multiple times

🟢 After (LET)

=LET(avg, AVERAGEIF(A2:A100,"Sales",C2:C100), IF(avg > avg*0.9, "Above", "Below")) Calculate once, reference by name. Clean and performant.
🚀 ETL Parallel: SQL CTEs / WITH clause, Spark .withColumn() + variables, dbt Jinja macros, UDFs in Databricks
DATA RESHAPING (2024)

VSTACK / HSTACK / GROUPBY

=VSTACK(array1, array2, ...)

=GROUPBY(row_fields, values, function)

VSTACK/HSTACK combine arrays vertically or horizontally — like UNION ALL in SQL. GROUPBY and PIVOTBY bring native aggregation and pivoting, turning Excel into a true data transformation engine.

🔴 Before (Manual copy + Pivot Tables)

Copy-paste sheets together, create Pivot Table, refresh manually Static, breaks on data changes, separate pivot cache

🟢 After (VSTACK + GROUPBY)

=GROUPBY(VSTACK(Sheet1!A:B, Sheet2!A:B), VSTACK(Sheet1!C:C, Sheet2!C:C), SUM) Dynamic union + aggregation in a single formula
🚀 ETL Parallel: SQL UNION ALL + GROUP BY, Spark .union() + .groupBy().agg(), dbt union + group by, Databricks merge/aggregate

The Formula Pipeline

=SORT(UNIQUE(FILTER(VSTACK(Sales!A:D, Returns!A:D), VSTACK(Sales!B:B, Returns!B:B)>1000)), 3, -1)

Union two sheets → Filter by amount → Deduplicate → Sort descending. One formula. Zero VBA. Pure data engineering.
